## 🎯 วัตถุประสงค์และภาพรวมการเรียนรู้ (Executive Summary & Learning Objectives)

ยินดีต้อนรับสู่ใบงานปฏิบัติการวิทยาการรหัสลับฉบับผู้เริ่มต้น! ในใบงานนี้ ท่านจะได้เรียนรู้และลงมือปฏิบัติจริงว่ามนุษยชาติปกป้องความลับมาตลอดประวัติศาสตร์ได้อย่างไร ตั้งแต่รหัสลับทางทหารของจูเลียส ซีซาร์ (Julius Caesar), ความมหัศจรรย์ของตรรกะระดับบิต XOR, การเข้ารหัสลับแบบสมมาตร AES ที่ปกป้องแอปธนาคารในปัจจุบัน ไปจนถึงกลไกกุญแจสาธารณะ (Public-Key Cryptography) ที่เป็นกระดูกสันหลังของอินเทอร์เน็ตที่ปลอดภัย (HTTPS)

เมื่อทำใบงานนี้สำเร็จ ท่านจะมีความรู้ความสามารถในด้าน:
1. **เข้าใจรหัสลับคลาสสิกและการวิเคราะห์ความถี่:** ลงมือเขียนโค้ด Caesar Shift Cipher, เข้าใจว่าเหตุใดการเลื่อนตัวอักษรแบบธรรมดาจึงถูกถอดรหัสได้ง่ายดาย และเข้าใจว่าทำไมตัวดำเนินการบิตไวส์ XOR ($A \oplus B \oplus B = A$) จึงเป็นหัวใจสำคัญของการเข้ารหัสลับดิจิทัลทุกชนิด
2. **เชี่ยวชาญการเข้ารหัสลับสมมาตรยุคใหม่ (AES-GCM):** เรียนรู้การทำงานของบล็อกไซเฟอร์, ทำความเข้าใจว่าเหตุใดโหมดที่บกพร่องอย่าง "ECB" จึงทำลายความลับของข้อมูล (ตัวอย่างภาพนกเพนกวิน "AES Penguin" อันโด่งดัง) และเรียกใช้ไลบรารีมาตรฐานสากล `cryptography` ในภาษา Python เพื่อสร้างการเข้ารหัสลับ AES-256-GCM ที่ตรวจจับการดัดแปลงข้อมูลได้
3. **ไขความลับของระบบกุญแจสาธารณะ (Diffie-Hellman & RSA):** สัมผัสความมหัศจรรย์ของการตกลงกุญแจลับร่วมกันผ่านเครือข่ายอินเทอร์เน็ตสาธารณะที่มีผู้ดักฟัง โดยที่ผู้ดักฟังไม่มีทางล่วงรู้กุญแจลับนั้นได้เลย พร้อมทดลองเขียนระบบจำลอง RSA ขนาดเล็ก
4. **ตรวจสอบความถูกต้องสมบูรณ์ด้วยฟังก์ชันแฮช (SHA-256):** เข้าใจความแตกต่างระหว่างการแฮชและการเข้ารหัสลับ, ทำความเข้าใจบทบาทของค่าแฮชในฐานะลายนิ้วมือดิจิทัล และวัดผลการทดลอง "ปรากฏการณ์หิมะถล่ม (Avalanche Effect)" ที่การเปลี่ยนตัวอักษรเพียงตัวเดียวทำให้ผลลัพธ์เปลี่ยนไปโดยสิ้นเชิง

### งาน 2.1: การเข้ารหัสและถอดรหัสซีซาร์ (Caesar Cipher)
* `caesar_encrypt(plaintext: str, shift: int) -> str`:
  * เลื่อนตัวอักษรภาษาอังกฤษไปข้างหน้าตามค่า `shift` มอดุโล 26: $C_i = (P_i + \text{shift}) \bmod 26$
  * คงสถานะตัวพิมพ์ใหญ่และตัวพิมพ์เล็กตามเดิม (`'A'..'Z'` และ `'a'..'z'`)
  * ตัวอักษรอื่นๆ (ช่องว่าง, ตัวเลข, เครื่องหมายวรรคตอน) จะต้องคงเดิมไม่เปลี่ยนแปลง
  * รองรับค่าการเลื่อนที่มากกว่า 26 หรือค่าติดลบด้วยการใช้ `% 26`
* `caesar_decrypt(ciphertext: str, shift: int) -> str`:
  * ทำการย้อนกลับการเลื่อน: $P_i = (C_i - \text{shift}) \bmod 26$ (หรือเรียก `caesar_encrypt(ciphertext, -shift)`)

### งาน 2.2: สตรีมรหัสลับระดับบิตด้วยตัวดำเนินการ XOR
* `xor_cipher(data: bytes, key: bytes) -> bytes`:
  * รับข้อมูลในรูปไบต์ `data` และทำการ XOR (`^`) ทีละไบต์กับ `key` ที่วนซ้ำตามความยาว
  * สูตร: $C_i = \text{Data}_i \oplus \text{Key}_{i \bmod \text{len(Key)}}$
  * แสดงคุณสมบัติพิเศษของ XOR ที่สามารถถอดรหัสกลับได้ทันทีเมื่อเข้ารหัสซ้ำด้วยกุญแจเดิม: $(A \oplus B) \oplus B = A$

### งาน 2.3: ตัวหารร่วมมากด้วยขั้นตอนวิธีของยุคลิด (Euclidean GCD)
* `euclidean_gcd(a: int, b: int) -> int`:
  * พัฒนาขั้นตอนวิธีของยุคลิดเพื่อหาตัวหารร่วมมาก (ห.ร.ม.) ของจำนวนเต็มบวก $a$ และ $b$
  * ทำการวนลูป `a, b = b, a % b` จนกระทั่ง `b == 0` แล้วส่งค่า `a` กลับคืน

### งาน 2.4: การเข้ารหัสลับสมมาตรยุคใหม่: AES-256-GCM
* `aes_gcm_encrypt(plaintext: str, key: bytes) -> tuple[bytes, bytes]`:
  * เรียกใช้ `AESGCM` จากไลบรารี `cryptography.hazmat.primitives.ciphers.aead`
  * สุ่มสร้าง Nonce ขนาด 12 ไบต์ (96 บิต) อย่างปลอดภัยด้วย `secrets.token_bytes(12)`
  * เข้ารหัสข้อความและส่งคืนค่า `(nonce, ciphertext)`
* `aes_gcm_decrypt(nonce: bytes, ciphertext: bytes, key: bytes) -> str`:
  * ถอดรหัสข้อความลับด้วยกุญแจและ Nonce เดิม
  * ตรวจสอบความถูกต้องของ Authentication Tag ขนาด 16 ไบต์ หากมีใครแอบแก้ไขข้อความแม้แต่ 1 บิต ระบบจะแจ้งข้อผิดพลาดทันที!

### งาน 2.5: การแลกเปลี่ยนกุญแจลับ Diffie-Hellman
* `dh_compute_public_key(g: int, priv_key: int, p: int) -> int`:
  * คำนวณกุญแจสาธารณะ $A = g^{\text{priv\_key}} \bmod p$ ด้วยฟังก์ชันยกกำลังแบบเร็ว `pow(g, priv_key, p)`
* `dh_compute_shared_secret(peer_public_key: int, my_priv_key: int, p: int) -> int`:
  * คำนวณกุญแจลับร่วม $S = (\text{peer\_public\_key})^{\text{my\_priv\_key}} \bmod p$
  * พิสูจน์ว่า Alice และ Bob จะได้กุญแจลับ $S$ ที่ตรงกันเป๊ะโดยไม่ต้องส่งค่า $S$ ผ่านเครือข่ายเลย!

### งาน 2.6: กล่องนิรภัยกุญแจสาธารณะจำลอง: Toy RSA
* `rsa_encrypt_toy(m: int, e: int, n: int) -> int`:
  * เข้ารหัสข้อความตัวเลข $m$ ด้วยกุญแจสาธารณะ $(n, e)$: $C = m^e \bmod n$
* `rsa_decrypt_toy(c: int, d: int, n: int) -> int`:
  * ถอดรหัสข้อความตัวเลข $c$ ด้วยกุญแจส่วนตัว $(n, d)$: $M = c^d \bmod n$

# 🕵️ ส่วนที่ 3: ภารกิจสายลับ

### ภารกิจ 3.1: ถอดรหัสข้อความสายลับและตรวจสอบความถูกต้องด้วย SHA-256
* **สถานการณ์จำลอง:**
  หน่วยงานข่าวกรองดักจับสัญญาณวิทยุที่ถูกเข้ารหัสลับได้:
  `"AOL ZLJYLA HNLUA PZ TLLAPUN HA TPKUPNOA"`
  สายลับรายงานว่าในข้อความนี้จะต้องมีคำสำคัญคือคำว่า `"AGENT"`
* **สิ่งที่ต้องปฏิบัติ:**
  1. พัฒนาฟังก์ชัน `crack_simple_caesar(ciphertext: str, clue_word: str = "THE") -> tuple[int, str]`:
     * วนลูปทดสอบคีย์การเลื่อนทั้ง 26 ค่า ($0..25$)
     * ถอดรหัสข้อความด้วยแต่ละคีย์
     * หากพบคำว่า `clue_word` อยู่ในข้อความ ให้ส่งคืนค่า `(shift, candidate)`
  2. พัฒนาฟังก์ชัน `compute_sha256_hex(text: str) -> str`:
     * คำนวณลายนิ้วมือดิจิทัล SHA-256 ด้วย `hashlib.sha256()`
     * ตรวจสอบว่าข้อความที่ถอดรหัสได้ ตรงกับค่าแฮชมาตรฐานที่ระบุไว้

### ภารกิจโบนัส 3.2: ปรากฏการณ์ปีกผีเสื้อ (Avalanche Detector)
* พัฒนาฟังก์ชัน `measure_hash_avalanche(text1: str, text2: str) -> float`:
  * เปรียบเทียบข้อความ 2 ข้อความที่ต่างกันเพียงแค่ตัวอักษรเดียว
  * แปลงรหัสแฮช SHA-256 ของทั้งสองข้อความเป็นสตริงบิตไบนารี 256 บิต
  * คำนวณว่ามีบิตที่เปลี่ยนไป (Flip) คิดเป็นกี่เปอร์เซ็นต์
  * ในฟังก์ชันแฮชที่ดี บิตควรจะสุ่มพลิกผันประมาณ **50%**!
